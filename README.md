## 🍴 How to Fork & Deploy

1. **Fork the repo**
   Click **Fork** at the top right of [the repository page](https://github.com/gpaxton428-collab/Paxton-MD), or go straight to the [fork page](https://github.com/gpaxton428-collab/Paxton-MD/fork).

2. **Clone your fork**
   ```bash
   git clone https://github.com/<your-username>/Paxton-MD.git
   cd Paxton-MD
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Get your session string**
   Visit the [Session Generator](https://paxton-md-session-generator.onrender.com/), link your WhatsApp, and copy the session string it gives you.

5. **Set up your environment**
   ```bash
   cp .env.example .env
   ```
   Open `.env` and paste your session string into `SESSION_ID=`. Fill in any optional API keys you want (chatbot, weather, etc.) — see the comments in `.env.example` for where to get each one.

6. **Run it**
   ```bash
   npm start
   ```

7. **Deploy to a host** (Render, Railway, a VPS, or a bot panel)
   - Push your fork to your own GitHub.
   - Connect it to your host of choice.
   - Set the same variables from `.env` in your host's Environment Variables dashboard (never commit real secrets to a public repo).
